# 作业一 · 数据采集

## 任务目标

掌握网络数据采集的基本流程：发起 HTTP 请求 → 解析页面 → 结构化存储。

## 任务要求

1. 自选一个公开数据源（天气、图书榜单、电影排行、新闻列表等均可）
2. 使用 `requests` 获取页面内容，使用 `BeautifulSoup` 解析
3. 至少采集 **100 条**有效记录，字段不少于 4 个
4. 将结果保存为 `data/raw_data.csv`，UTF-8 编码

## 提交物

| 文件 | 说明 |
| --- | --- |
| `collect.py` | 采集脚本，可直接运行 |
| `data/raw_data.csv` | 采集结果（小于 5 MB 时提交） |
| `report.md` | 实验报告 |

## 报告需包含

- 数据来源与网址
- 采集字段设计与含义
- 关键代码说明
- 遇到的问题与解决方法

## 知识点

HTTP 请求与响应、HTML 结构解析、CSV 写入、请求头伪装、采集频率控制

## 合规提醒

- 遵守目标网站的 `robots.txt`，不采集明确禁止的内容
- 控制请求频率，避免对目标站点造成压力
- 不采集个人隐私信息
