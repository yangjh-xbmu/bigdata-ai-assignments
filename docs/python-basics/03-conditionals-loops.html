单选第 1 级 · 概念

在 if / elif / else 里，当所有条件都不成立时，会执行哪一块？

else 是「兜底」分支，前面全都不满足时才轮到它。

单选第 1 级 · 概念

比较 5 == 5 的结果是什么类型、什么值？

相等比较成立时返回布尔值 True，不是数字 5 或 1。

单选第 1 级 · 概念

range(3) 依次产生哪些数？

range 从 0 开始、到「结束值减 1」为止，所以 range(3) 是 0,1,2。

单选第 1 级 · 概念

在 if 判断里，空列表 [] 会被当成什么？

0、空串、空列表、None 在布尔语境里都是假，所以 if [] 不会进分支。

单选第 2 级 · 辨析

执行 x = 0 后，下面代码会打印什么？

0 在布尔语境里是假，所以 if x 不成立，走 else 打印 b；这是「0 即假」最易踩的坑。

单选第 2 级 · 辨析

not (5 > 3) 的结果是？

5>3 是 True，not 取反得 False；注意 not 作用于整个括号，顺序别搞错。

单选第 2 级 · 辨析

for i in range(1, 6): 的循环体一共会执行几次？

range(1,6) 是 1,2,3,4,5，左闭右开所以不含 6，共 5 次；别顺手加一。

单选第 2 级 · 辨析

在 while 循环体里，想「立刻结束整个循环」，该用哪个？

break 直接跳出整层循环；continue 只是跳过本轮、还会回去再判断，别混。

单选第 3 级 · 应用

有温度列表 temps = [20, 35, 18, 40]，想打印出所有 ≥ 35 的值，正确写法是？

要逐个检查并只打印达标的，必须 for 遍历 + if 判断；B 打印的是布尔值，C 拿整个列表比大小会报错。

单选第 3 级 · 应用

numbers = [1, 2, 3, 4]，想统计其中偶数的个数，下面哪句填在 if n % 2 == 0: 下面最合适？

计数用累加 count += 1；写 count = 1 每次都归一成 1，最后永远只记到 1。

单选第 3 级 · 应用

遍历用户名单逐个发送通知，遇到「退订」就停止继续发送，应当用？

「停止继续发送」是结束整个循环，用 break；continue 只会跳过这一位、后面照发不误。

单选第 3 级 · 应用

给定 scores = [4.5, 2.0, 3.8, 1.5, 5.0]，要正确统计「低于 3 的个数」，下面哪段能办到？

统计个数要累加 low += 1；B、C 把计数写死成常量，D 只打印不计数，都得不到个数。
