单选第 1 级 · 概念

type(3.0) 的结果是什么？

只要带小数点，Python 就归为 float，哪怕它的数值是整数。

单选第 1 级 · 概念

input() 拿回来的数据是什么类型？

input() 一律返回字符串，要参与算术必须自己用 int() 或 float() 转换。

单选第 1 级 · 概念

下面哪个是合法的变量名？

变量名不能以数字开头、不能含连字符、不能占用保留关键字；小写加下划线是 Python 的通行写法。

单选第 1 级 · 概念

执行 is_ok = True 之后，type(is_ok) 是什么？

True / False 是布尔类型；一旦写成 "True"（带引号）就变成字符串了。

单选第 2 级 · 辨析

"3" + 1 会得到什么？

Python 不会替你猜「3」是数字还是文字，类型对不上就直接报 TypeError，必须显式转换。

多选第 2 级 · 辨析

关于变量，下面哪些说法是对的？

Python 是动态类型，赋值即定义；age = 18 之后写 age = "十八" 也完全合法。

单选第 2 级 · 辨析

print(1 + 2) 和 print("1" + "2") 分别输出什么？

同一个符号两种含义：数字上是加法，字符串上是拼接。

单选第 2 级 · 辨析

int("3.14") 会怎样？

int() 不接受带小数点的字符串；要两步走：int(float("3.14"))。

单选第 3 级 · 应用

要让下一行 print(age + 10) 正常工作，age 应该怎么写出来？

A 拿到的是字符串，加 10 会报 TypeError；D 的 print 返回 None。只有 B 一步到位得到整数。

单选第 3 级 · 应用

已知 scores = [88, 92, 90]，下面哪一句会报错？

A 让字符串去加一个 float，类型不匹配；B 用 f-string、C 用逗号分隔、D 手动 str()，都不需要隐式转换。

单选第 3 级 · 应用

学生问：为什么 print(0.1 + 0.2) 出来的是 0.30000000000000004？

这是所有使用二进制浮点的语言共有的特性，不是 Python 的错；比较大小用 abs(x - y) < 1e-9。
