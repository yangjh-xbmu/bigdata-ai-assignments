分级自测

三级递进：概念(1) → 辨析(2) → 应用(3)。题目一道一道出：先自己选，再「检查本题」；全部作答后自动出成绩。

单选第 1 级 · 概念

对 s = "兰州牛肉面"，s[0] 取到的是哪个字？

Python 索引从 0 开始，第一个字符是 s[0]，不是 s[1]。

单选第 1 级 · 概念

len("牛肉面") 的结果是几？

len 数的是字符个数，"牛肉面" 共三个字，所以是 3。

单选第 1 级 · 概念

想把 "a b c" 按空格拆成列表，用哪个方法？

split 负责把字符串按分隔符拆开；join 正好相反，是把列表拼成串。

单选第 1 级 · 概念

下面哪一对括号用来书写列表的字面量？

列表用方括号 []；圆括号是元组、花括号是字典/集合。

单选第 2 级 · 辨析

执行 s = "兰州" 之后，再写 s[0] = "面" 会怎样？

字符串是不可变对象，不能用下标去改其中一位；要改必须新建，如 s = "面" + s[1:]。

单选第 2 级 · 辨析

"a,b,c".split(",") 得到的是什么？

split 按逗号把原串切开，返回的是列表；分隔符本身不会留在结果里。

单选第 2 级 · 辨析

执行 s = "兰州" 后，再写 t = s.replace("兰","面")，此时 s 本身是什么？

字符串方法返回新串、不改动原串；想保留结果要写 s = s.replace(...)。

单选第 2 级 · 辨析

lst = [1, 2, 3, 4]，执行 v = lst.pop() 之后，lst 和 v 分别是什么？

pop 删掉最后一个元素并返回它；所以列表少一个尾巴，v 拿到被删的那个值。

单选第 3 级 · 应用

有 s = "西北民族大学"，想取出最前面的两个字「西北」，下面哪句正确？

前两个字要位置 0 和 1，写 s[0:2]；s[-2:] 取的是末尾两字，s[2:] 跳过前两字。

单选第 3 级 · 应用

有评论 s = "这家面真不错"，想把它变成「每个字一个元素」的列表，该用哪句？

中文没有空格，split() 拆不开；list(s) 才能按字符逐个拆成列表。

单选第 3 级 · 应用

words = ["好评","差评","好评"]，想删掉其中一个「差评」，正确写法是？

按值删除用 remove；pop 按位置删、且需要下标或返回被删项，没有 delete/del 这种列表方法。

单选第 3 级 · 应用

有一个商品列表 prices，想逐个打印出来，正确写法是？

Python 的遍历固定写法是 for 变量 in 可迭代对象:，冒号和缩进都不能省，没有 each/as 这种写法。
