单选第 1 级 · 概念

17 % 5 的结果是多少？

% 求余数：17 里能装 3 个 5，剩 2。商是 17 // 5 = 3，余数是 17 % 5 = 2。

单选第 1 级 · 概念

7 / 2 的结果是什么？

Python 3 里 / 是真除法，结果一律是 float；想要整除用 //。

单选第 1 级 · 概念

2 ** 10 的结果是多少？

** 是乘方，2 的 10 次方等于 1024，不是 2 乘以 10。

单选第 1 级 · 概念

下面哪一句会把 score 变大 10 之后再存回它自己？

+= 是「加完再存回去」；== 只出真假；score + 10 算完就丢，没存回变量；D 是语法错误。

单选第 2 级 · 辨析

-7 // 2 的结果是多少？

// 是向下取整，往数轴左边走：-3.5 向下的整数是 -4，不是抹掉小数位得 -3。

单选第 2 级 · 辨析

"ab" * 2 和 [1, 2] + [3] 分别得到什么？

同一个 * 在字符串上是重复；+ 在列表上是拼接，不是把对应位置相加。

单选第 2 级 · 辨析

某人写下 avg = 0.1 + 0.2 后判断 if avg == 0.3:，结果条件不成立。原因是什么？

浮点存储精度问题，不是 bug。比较小数用容差：abs(avg - 0.3) < 1e-9。

多选第 2 级 · 辨析

关于 and / or / not，下面哪些说法是对的？

逻辑运算要求的是「真值」，任何对象都能参与判断：0、""、[]、None 都算假，非空非零算真。C 不会报错。

单选第 3 级 · 应用

只有能被 4 整除、并且不能被 100 整除的年份才是闰年（能被 400 整除的也算）。下面哪个条件写对了？

A 漏了「能被 400 整除」的例外（2000 年是闰年却被排除）；C 用 / 得到的是小数，永远不等于 0；D 把 == 写成了 = ，语法错误。括号在 or 与 and 混用时不能省。

单选第 3 级 · 应用

要把 3725 秒换算成「1 小时 2 分 5 秒」，依次该怎么算？

先用 // 取整份得小时；再对 3600 取余拿到剩下的 125 秒，除以 60 取整得分钟；最后 % 60 得秒数。每一级都是「先取整份、再取余」。

单选第 3 级 · 应用

页面上要输出「已选 3 件，共 45 元」，其中 n = 3、price = 45.0。下面哪一句会报错？

D 用 + 把字符串和 int 连起来，报 TypeError。要拼字符串，必须先 str() 转换，或者改用 f-string。

单选第 3 级 · 应用

某人想在评分为 0 到 5 的列表里数出所有 5 分（满分）的个数，写成 count = 0，循环里 if s == 5: count += 1。有学生问：为什么不能写成 if s = 5:？

= 是赋值语句不是判断；不写成 == 就得不到真假值，Python 直接拒绝执行。
