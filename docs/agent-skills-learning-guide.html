Agent Skill 是什么？看图就懂

一小段图解 + 分级小测试。适合已经把「智能体会调用工具」弄明白的学习者。

01它很聪明，可不一定「会干你的活」

它缺的不是知识 缺的是「你家的工作做法」 做法每次重讲一次，又累又容易不一样

02Skill = 一个文件夹：做法 + 小工具 + 资料

像给新同事的入职手册 不用背下全书，需要时翻对应章节

03关键机制：需要多少，就读多少（渐进式披露）

第1层 极小 第2层 几千字内 第3层 平时为 0

04它干活时，一步步怎么来

它自己判断何时用，不用你每次指路 中间要数据 → 伸手（Tool / MCP）去取

05四样东西怎么分工，别混

Skill 不是更长的一段提示 Skill 不是工具本身 常组合：书中流程 → 伸手调数据

06一本册子到处能用（但陌生人的书要先检查）

Skill 现在已是开放格式，多家产品通用 册子能指挥机器人做事 → 恶意册子会闯祸，只信来源干净的

分级自测：检验你「真懂了」还是「看着像懂了」

三级递进：先问事实 → 再考分辨 → 最后考你现场判断。每题点「检查」看对错与一句话解析。
