# Visual Lesson Builder（图解学习资料生成器）

## Purpose

将任意一个概念做成一份**视觉化、低文字、严肃**的自包含 HTML 学习资料：上半部分是“看图就懂”的知识区，下半部分是分级递进的自测题。成品以单文件 HTML 交付，可直接浏览器打开，无外部依赖。

## 铁律（来自真实用户反馈，违反即返工）

1. **图形优先，文字极简**：能画出来就不写出来。知识区每节 = 一句话标题 + 一张自绘 SVG + 至多一句图注。整页正文段落式文字几乎为零。SVG 图内只放短标签。
2. **讲法“五岁也能懂”，但画面严肃**：用生活化具体类比组织内容（文件夹、抽屉、小工具、插座、入职手册…），一步步推进。但**禁止卡通、漫画、笑脸、可爱脸谱、表情符号、贴图风**。用户是严肃学习者。
3. **任务是讲清概念，不是展示资料**：内容需要事实核查时，先悄悄快速查证（最好依据权威出处），但**成品不得罗列来源清单、不得宣扬“我查了多少权威资料”**，最多留一行不起眼的出处/日期小字。
4. **视觉克制**：中性灰（ink/grey/line）+ 至多一个低饱和强调色；浅色底、白卡片。不使用彩色图标、图标字体、emoji、渐变堆砌。对错反馈用克制的绿/红小色块即可。
5. **测验分级且一题一题出**：
   - 三级递进：第1级 概念理解（基本事实）→ 第2级 辨析与机制（易混概念、机制原因）→ 第3级 应用与设计（场景决策）。每级 4 题左右，共 12 题上下。
   - **绝不全量铺开**：页面一次只显示一道题，用「上一题 / 下一题」线性推进。
   - 每题即时判分；「看答案」可作弊查看但**不计入正确数**（要在 UI 上说明）。
   - 全部作答完再展示分级与总分成绩与一句学习建议；可“重新作答”。
   - 单选用同 name 的 radio；多选/场景用 checkbox，data-answer 为升序字母串；判断题给 A(对)/B(错) 两项。
6. **交付前必须截图自查排版**：渲染成品截图逐屏检查文字溢出、图形重叠、错位、题目切换是否正常，修完再交付。

## 工作流

### Step 1 — 确认任务范围
若用户未说明主题/概念，先问清“要讲哪个概念”。明确受众：默认按“已具备基本前置知识的学习者”讲解，不教无关基础。

### Step 2 — 快速事实核查（轻量，不展示）
从权威出处核对该概念的**核心定义、关键机制、易混淆点**（必要可用一次网页检索/抓取，控制在一两个来源）。只需提取可用于正确绘图的事实点，并**记录出处 URL 备查**，不写入正文。

### Step 3 — 设计知识区“场景列表”
把概念拆成 3–8 个“一图一节”的场景，每节一个简单想法，尽量选生活化类比。常用推进顺序：
1. 痛点/为什么需要它（对比图）
2. 核心概念的结构/组成（解剖图）
3. 关键机制/工作原理（分层、时序、流程）
4. 一次典型运行的逐步示意
5. 易混概念边界辨析（对比矩阵/分工图）
6. 落地/生态/安全注意（复用与风险）

### Step 4 — 基于模板起步
复制 `assets/starter-template.html` 作为骨架（含全部 CSS 变量、知识区版式、**一题一题出的测验引擎与成绩逻辑**），不要从零手写 JS。

### Step 5 — 实现每节 SVG
- viewBox 统一 `0 0 760 <高>`，`width:100%`，浅色几何：白底圆角矩形 + 浅灰描边 + 少量强调色高亮块。
- 用抽象几何图形（圆角矩形、圆、折线、短箭头、文档/文件夹/芯片等简易线框）表达；可含 2–4 个“图形点”的横向故事条（帧式），但**不是漫画**——无表情、无角色化。
- 图内文字 11–16px，只放必要短标签；中文用系统字体即可。
- 文字勿贴边、勿重叠；行距拉开。svg text 需显式给 font-size 与 fill。

### Step 6 — 填入测验题
用模板内题目卡注释规范写题（data-lvl / data-answer / why-src 解析）。题不要出得太浅：第2级必须考“易混概念区分或机制原因”，第3级给场景让用户做设计/风险判断。每题解析压成一句话。

### Step 7 — 截图自查排版（交付前必做）
用浏览器自动化（如 agent-browser）打开本地文件，分屏截图：
- 顶部头部与知识区各节：有无文字溢出、SVG 错位/重叠/超出卡片、图注与图是否对得上。
- 测验区：第一题是否单独显示、切换上一/下一题是否正常、判分与成绩面板是否正常出现。
发现问题即修复 CSS/坐标，重新截图直到干净。

### Step 8 — 交付
用 present_files 打开成品；回复只说结论与最少的引导（如“知识区 6 图 + 12 题”），不要长篇讲解内容、不要罗列资料出处。

## 模板关键约定（改动时保持兼容）
- 颜色一律走 CSS 变量，禁止裸写五彩。
- `.qcard` 负责一题；切换逻辑依赖 `data-lvl`、`data-answer`、`.check/.peek` 按钮与 `.why-src` 解析区。删改这些会导致计分失效。
- 题目容器 `#qdeck` 与成绩面板 `#result` 的 id 被 JS 引用，勿重命名。

## 设计自查清单（交付前过一遍）
- [ ] 知识区正文几乎没有段落，全是“标题+图+一句图注”
- [ ] 没有卡通/emoji/彩色图标；颜色 ≤ 灰阶 + 1 强调色
- [ ] 每张图在窄屏不破版、文字不溢出
- [ ] 测验一次只显示一题；上一题/下一题可用；判分即时
- [ ] “看答案”不计分且已向学习者说明
- [ ] 每题都有 why-src 一句话解析；答案与 data-answer 一致
- [ ] 没有展示权威资料数量/来源大列表
