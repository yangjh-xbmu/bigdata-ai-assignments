# 2026-09-17

## 设计：Python + AI 四次课学习地图（待宏哥核定，尚未落盘）

- 需求：4 次课学完 Python 核心语法，再用 Python 学 AI 基础理论与应用（情感分析、文本分类）；每次课分上下两个 45 分钟，共 8 单元 / 360 min。
- 推荐方案（B 阶梯式）：Python 核心 5 单元（225 min）+ 文本与 AI 3 单元（135 min），贯穿项目为「中文评论情感分析」。转折点在第 3 次课下半场（jieba 分词 + 词频）。
- 对比方案 A（7:1，语法优先，AI 只能演示）、C（每次课上下半场双线并行，第 1 次课学生无能力做应用）。
- 明确不讲：自定义类与面向对象、装饰器、生成器、多线程、高级正则。
- 待定项：学生先修基础、中文/英文语料、运行环境（Notebook vs .py）、是否配课后作业。
- 落位建议（核定后）：`docs/learning-map.md`；若要可视化版本，参考本仓库 `docs/agent-skills-learning-guide.html` 的风格另出 HTML。

## 需求变更（同日上午，宏哥修正）

- 关键新信息：**整个学期还剩 13 次课，其中后 9 次才是人工智能理论与应用**。这 4 次课的唯一目标是「掌握足够用的 Python 基础」，不再包含 AI 内容。
- 改版后切分：语言核心 5 单元（225 min）+ 工程能力 3 单元（135 min）。
  - U1 变量·类型·输入输出 / U2 字符串·列表 / U3 条件·循环 / U4 字典·集合·推导式 / U5 函数
  - U6 模块·标准库·pip / U7 文件读写·异常处理 / U8 类与对象·调试
- 「够用」的判据：每个单元对应后面 AI 课的具体环节（清洗文本列、筛选、词频统计、封装函数、装库、读 CSV、看懂 sklearn 的 fit/predict API）。
- 教学节奏定为：每 45 min = 20 讲 + 20 敲 + 5 收；每次课固定 5 min「故意制造报错」训练读 traceback。
- 已剔除：numpy / pandas / matplotlib（划归后续 AI 课）、jieba 分词、TF-IDF、情感分析、sklearn 建模。
